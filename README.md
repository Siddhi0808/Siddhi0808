<h3>🔍 GroundTruth AI — Hallucination Detection</h3>
<sub><b>Problem:</b> LLMs give confident answers that your own documents don't support.</sub>
<p>
A REST API that checks an LLM's answer against a 1,900-chunk knowledge base.<br/>
Retrieves evidence with pgvector search and grades it with a local Llama 3.2 judge.<br/>
Held-out testing exposed an overfit rule engine (90.8% → 72.0%).<br/>
154 tests run in GitHub Actions against real Postgres.
